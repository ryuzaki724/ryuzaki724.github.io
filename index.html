🖥️ How to Use the Application

Once Ea App Desktop is installed, open it from your desktop shortcut or Start menu. The main window shows a simple layout. You will see a button to select your Ea App library folder. Click that button and browse to the folder where your screenshots and workshop files are stored. The application will remember this location for next time.

Next, you will see a "Create Backup" button. Click it. The application will ask you to confirm. It will then create a new folder with today's date inside your chosen library folder. Inside that dated folder, you will find copies of your screenshot and workshop files. That's it. You can repeat this process whenever a patch is announced. The old dated folders remain untouched, so you can always access previous versions.

If you want to change the library folder later, simply click the "Change Folder" button and pick a new location. The application keeps a small log of when backups were created. You can view this log from the main window by clicking "View History." This helps you keep track of your backups over time.

No. The application only makes copies. Your original screenshot and workshop files remain exactly where they are. The tool simply creates a new dated folder with duplicates.

No, Ea App Desktop is designed for Windows computers only. It will not run on macOS or Linux.

How often should I create a backup?

We recommend creating a backup before every patch or update. You can also create backups regularly, such as once a week, to keep your files safe.

Where are my backups stored?

Backups are stored inside the library folder you selected. Each backup is in a subfolder named with the date, for example "2026-01-15". You can open that folder anytime using File Explorer.
